### 深度分析（5B）

- **和 GPT-3 的关键区别**：GPT-3 用了私有数据（WebText2），LLaMA **全是公开数据**——这是开源的前提
- **大部分只训练 1 epoch**：避免记忆，但可能浪费数据
- **数据质量严格**：CCNet pipeline 对 CommonCrawl 做了去重、语言识别、质量过滤、Wikipedia 参考分类
- **面试价值**：面试中问"LLaMA 的训练数据有什么特点"——纯公开数据、多样化来源、~1.4T tokens

## Table 2: 模型配置

### 客观描述（5A）

4 种规模：7B (32层/4096维) → 13B (40层/5120维) → 32B (60层/6656维) → 65B (80层/8192维)

### 深度分析（5B）

- 7B/13B 用 1T tokens，32B/65B 用 1.4T——大模型用更多数据
- 所有模型 batch size = 4M tokens
- LR 随规模减小：3e-4 (7B/13B) → 1.5e-4 (32B/65B)
