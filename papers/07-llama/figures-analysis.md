## Table 1: 训练数据混合

### 客观描述（5A）

| 数据源 | 采样比例 | Epochs | 磁盘大小 |
|--------|---------|--------|---------|
| CommonCrawl | 67.0% | 1.10 | 3.3TB |
| C4 | 15.0% | 1.06 | 783GB |
| GitHub | 4.5% | 0.64 | 328GB |
| Wikipedia | 4.5% | 2.45 | 83GB |
| Books (Gutenberg+Books3) | 4.5% | 2.23 | 85GB |
| ArXiv | 2.5% | 1.06 | 92GB |
| StackExchange | 2.0% | 1.03 | 78GB |

### 深度分析（5B）

- **独立解读**：CommonCrawl 占 2/3 + C4 占 15% = 82% 来自网页数据。Wikipedia 和 Books 虽然只占 9%，但训练了 2+ epochs（高质量数据多看几遍）
- **对照 caption**："Data mixtures used for pre-training" — 与 tex 完全一致（67.0%, 15.0%, 4.5% 等精确数值）
- **验证的假设**：纯公开数据可以训练出接近 SOTA 的模型——开源的前提
- **批判**：大部分数据只训练 ~1 epoch。如果某些子集特别有价值（如 Wikipedia），多训练几个 epoch 的效果如何？论文没有做这个消融实验
- **面试价值**：面试中问"LLaMA 训练数据特点"，核心答案：纯公开数据 + 1.4T tokens + CCNet 严格过滤

## Table 2: 模型配置

### 客观描述（5A）

4 种规模：7B (32层/4096维/32头) → 13B (40层/5120维/40头) → 33B (60层/6656维/52头) → 65B (80层/8192维/64头)

- 所有模型 batch size = 4M tokens
- FFN 维度 = $\frac{2}{3} \times 4 \times d_{model}$（SwiGLU 补偿）
- 序列长度 = 2048

### 深度分析（5B）

- **FFN 维度调整**：标准是 $4 \times d_{model}$，但 SwiGLU 需要 3 个矩阵（多 50%）。LLaMA 调整为 $\frac{2}{3} \times 4 \times d_{model}$，让总参数量和标准 FFN 相当
- **训练成本**：65B 在 2048 A100 上训练 21 天 = ~43,000 A100 天。这比训练 540B 模型便宜得多
- **面试价值**：7B 和 13B 可以在消费级 GPU 上推理——这是"推理优先"策略的直接体现

## Table 3: 常识推理

### 客观描述（5A）

零样本准确率对比（tex 验证精确数值）：

| 模型 | BoolQ | PIQA | HellaSwag | WinoGrande |
|------|-------|------|-----------|-----------|
| GPT-3 175B | 60.5 | 81.0 | 78.9 | 70.2 |
| Chinchilla 70B | 83.7 | 81.8 | 80.8 | 74.9 |
| PaLM 540B | 88.0 | 82.3 | 83.4 | 81.1 |
| **LLaMA 65B** | **85.3** | **82.8** | **84.2** | 77.0 |

### 深度分析（5B）

- **LLaMA-65B vs PaLM-540B**：HellaSwag 84.2 > 83.4，PIQA 82.8 > 82.3——65B 在常识推理上超越 540B（参数只有 1/8）
- **LLaMA-13B vs GPT-3**：HellaSwag 79.2 > 78.9，PIQA 80.1 < 81.0——部分超越
- **批判**：BoolQ 上 LLaMA-65B (85.3) < PaLM-540B (88.0)——大模型在知识密集型任务上仍有优势
- **面试价值**：证明"小模型+多数据"在常识推理上的有效性

## Table 6: 阅读理解

### 客观描述（5A）

零样本 RACE 准确率：

| 模型 | RACE-middle | RACE-high |
|------|-----------|-----------|
| GPT-3 175B | 58.4 | 45.5 |
| PaLM 540B | 68.1 | 49.1 |
| **LLaMA 65B** | **67.9** | **51.6** |

### 深度分析（5B）

- **RACE-high 51.6 > PaLM-540B 49.1**——这是 LLaMA 最亮眼的结果之一。RACE-high 是高难度阅读理解，LLaMA-65B 用 1/8 参数胜过 PaLM-540B
- **为什么阅读理解提升大？** 更多训练数据 = 更多样的文本结构 = 更强的语言理解能力
- **面试价值**：LLaMA-65B 在阅读理解上超越 PaLM-540B = 更多数据 > 更多参数

## Table 7: 数学推理

### 客观描述（5A）

GSM8k maj1@k 结果（tex 验证）：

| 模型 | GSM8k pass@1 | GSM8k maj1@100 |
|------|-------------|---------------|
| PaLM 540B | 56.5 | - |
| Minerva 62B | 52.4 | 68.5 |
| **LLaMA 65B** | **50.9** | **69.7** |

### 深度分析（5B）

- **LLaMA-65B maj1@100 = 69.7 > Minerva 62B = 68.5**——虽然 Minerva 在 38.5B 数学 token 上专门微调过
- **但 pass@1 上 LLaMA-65B 50.9 < PaLM-540B 56.5**——大模型在单样本推理上仍有优势
- **面试价值**：通用模型 + 多数据可以接近专门微调模型的数学能力
