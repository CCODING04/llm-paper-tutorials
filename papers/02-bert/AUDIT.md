**预估新增**：~35 行

#### 3. 补充公式推导：NSP 损失 + 微调分类头完整推导

**问题**：
- NSP 损失只说"二分类"没给公式
- 微调分类头公式缺符号解释
- 问答起止概率没完整给出

**应该写什么**：

NSP 损失：
$$P(\text{IsNext} | C) = \text{softmax}(C \cdot W_{\text{NSP}}^T)$$
$$L_{\text{NSP}} = -\log P(y_{\text{NSP}} | C)$$
- 解释 $C$ 是 [CLS] 的输出、$W_{\text{NSP}} \in \mathbb{R}^{2 \times H}$

总预训练损失：
$$L = L_{\text{MLM}} + L_{\text{NSP}}$$

微调分类头：
$$P(y | x) = \text{softmax}(C W^T)$$
- $C \in \mathbb{R}^H$：[CLS] 输出
- $W \in \mathbb{R}^{K \times H}$：分类矩阵
- $K$：标签数
- 为什么是矩阵乘法而不是点积？（多分类需要 K 个权重向量）

SQuAD 起止概率：
$$P(i = \text{start}) = \frac{\exp(S \cdot T_i)}{\sum_j \exp(S \cdot T_j)}$$
- $S \in \mathbb{R}^H$：起始向量（唯一新增参数）

**预估新增**：~50 行

#### 4. 补充输入→输出追踪代码

**问题**：§2.5 只有文字版数据流图，缺少代码追踪和 MLM masking 的完整示例。

**应该写什么**：

#### 8. 补充从零实现 MLM 损失的代码

**问题**：现有代码都调用 HuggingFace pipeline，缺少"手动实现"来验证论文公式。

**应该写什么**：
```python
# 手动实现 MLM forward + loss
def mlm_forward(input_ids, masked_positions, masked_labels, model):
    outputs = model(input_ids)
    hidden = outputs.last_hidden_state  # [B, L, H]
    # 取 mask 位置的 hidden states
    mask_hidden = hidden[torch.arange(B), masked_positions]  # [B*mask_count, H]
    # 用 embedding 矩阵做分类
    logits = mask_hidden @ model.embeddings.word_embeddings.weight.T  # [B*mask_count, V]
    loss = F.cross_entropy(logits, masked_labels)
    return loss
```
