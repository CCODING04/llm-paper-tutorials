### ⚠️ 有误的关键数值 / 事实

**P0-1：MLA KV Cache 计算错误**

教程写道：
> `MLA cache = c_t^{KV} (512) + k_R (128 × 64 = 8192) ≈ 8704`

根据论文 eq 3：$\mathbf{k}_t^R = \text{RoPE}(W^{KR} \mathbf{h}_t)$，其中 $W^{KR} \in \mathbb{R}^{d_h^R \times d}$，输出维度为 $d_h^R = 64$。

论文 eq 4：$\mathbf{k}_{t,i} = [\mathbf{k}_{t,i}^C; \mathbf{k}_t^R]$ — **同一个** $k_t^R$ 被所有头共享。

因此：
- **正确缓存**: $c_t^{KV} (512) + k_t^R (64) = 576$
- **正确压缩比**: $32768 / 576 \approx 57x$（不是教程说的 32x）

教程错误地将 $k_t^R$ 计算为 $128 \times 64 = 8192$（假设每头一个独立的 RoPE key），但实际上论文设计是所有头共享一个 64 维的 RoPE key。

**影响**: 高。这是 MLA 的核心卖点——KV cache 压缩比。面试中可能会被追问。
