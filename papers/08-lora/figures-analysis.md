## Figure 1: LoRA 重参数化

### 客观描述（5A）
示意图：$W_0$（冻结，大矩阵）+ $B \cdot A$（可训练，两个小矩阵）
- $W_0 \in \mathbb{R}^{d \times k}$
- $B \in \mathbb{R}^{d \times r}$, $A \in \mathbb{R}^{r \times k}$
- 输出 $h = W_0 x + BAx$

### 深度分析（5B）
- 这是 LoRA 的核心——把大矩阵分解为两个小矩阵的乘积
- 面试价值：面试必考——画图解释 LoRA

## Table 1: 推理延迟对比

### 客观描述（5A）

### 深度分析（5B）
- **小 batch + 短序列**时 Adapter 延迟增加 **30%**——这是在线推理的典型场景
- LoRA 延迟和全量微调完全一样（合并后无额外计算）
- 面试价值：证明 LoRA 的"零延迟"优势在在线推理中尤其重要
