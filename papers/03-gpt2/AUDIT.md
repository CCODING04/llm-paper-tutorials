### 关键缺失项详细分析

#### ❌ 缺失 1：自回归目标函数推导

论文的核心数学对象是自回归语言模型目标：

$$\mathcal{L}(\theta) = -\sum_{i=1}^{n} \log p_\theta(s_i | s_1, ..., s_{i-1})$$

教程应该有独立的方法小节：
- 推导从链式法则出发
- 解释每个符号（$s_i$, $\theta$, 条件概率的物理含义）
- 直觉类比（如"预测下一个词就像填空题，只不过空在句子末尾"）
- 代码实现（从零实现自回归 LM 的前向传播）
- 与 BERT MLM 目标的对比

#### ❌ 缺失 2：代码验证

WORKFLOW Step 6 明确要求"可运行的代码 + 测试 + 预期输出"。当前教程零个代码块。需要至少：

1. **自回归 LM 实现**：定义模型 → 前向传播 → 计算 loss → 生成
2. **Byte-level BPE 简化实现**：基础词表 → 合并 → tokenize → 解码
3. **Pre-LN vs Post-LN 对比**：训练稳定性实验
4. **Scaling 趋势可视化**：复现 Figure 1 的趋势

#### ❌ 缺失 3：数据流追踪

缺少从原始文本到最终预测的完整数据流：

```
原始文本 "The cat sat"
    ↓ UTF-8 编码
字节序列 [84, 104, 101, 32, 99, 97, 116, 32, ...]
    ↓ Byte-level BPE
Token 序列 [464, 3749, 3187, ...]
    ↓ Token Embedding + Positional Encoding
嵌入矩阵 [seq_len, d_model]
    ↓ ×12 Transformer Blocks (Pre-LN, Self-Attention, FFN)
隐藏状态 [seq_len, d_model]
    ↓ LM Head (Linear → Softmax)
概率分布 [vocab_size]  → 取 argmax 得到下一个 token
```

#### ❌ 缺失 4：图表五步法

教程中 Figure 1 有分析但不是五步法格式。Figure 2-5 完全没有精读。需要为每张关键图表补充：
